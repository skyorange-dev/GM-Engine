#  GM Engine

基于 C++17 标准库实现的高并发小对象内存池（仿 TCMalloc 架构）。旨在解决原生 `malloc/free` 在多线程高频小对象分配场景下的锁竞争瓶颈与内存碎片问题。

## ✨ 核心特性

- **无锁快路径**：采用 `ThreadCache` 线程本地缓存架构，99% 的内存分配与释放全程无锁，时间复杂度严格 **O(1)**。
- **极致吞吐性能**：在 16 核并发环境下，单次分配/释放延迟低至 **8.53 ns**，峰值吞吐量突破 **1.17 亿次/秒**。
- **抗物理内存墙**：在跨越 L3 缓存、超 1GB 物理内存驻留的极限压测下，依然保持平稳的极低延迟。
- **极低元数据开销**：使用侵入式链表与定长切分，1GB 纯数据驻留下，管理元数据额外开销仅占 **1.05%**。
- **完美跨平台与生态**：完全基于 C++ 标准库，提供 `STL_PoolAllocator`，无缝兼容 `std::list`、`std::vector` 等容器。
