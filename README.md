# 🚀 高性能多线程小对象内存池 (High-Performance Multi-Thread Memory Pool)

基于 C++17 标准库实现的高并发小对象内存池（仿 TCMalloc 架构）。旨在解决原生 `malloc/free` 在多线程高频小对象分配场景下的锁竞争瓶颈与内存碎片问题。

## ✨ 核心特性

- **无锁快路径**：采用 `ThreadCache` 线程本地缓存架构，99% 的内存分配与释放全程无锁，时间复杂度严格 **O(1)**。
- **极致吞吐性能**：在 16 核并发环境下，单次分配/释放延迟低至 **8.53 ns**，峰值吞吐量突破 **1.17 亿次/秒**。
- **抗物理内存墙**：在跨越 L3 缓存、超 1GB 物理内存驻留的极限压测下，依然保持平稳的极低延迟。
- **极低元数据开销**：使用侵入式链表与定长切分，1GB 纯数据驻留下，管理元数据额外开销仅占 **1.05%**。
- **完美跨平台与生态**：完全基于 C++ 标准库，提供 `STL_PoolAllocator`，无缝兼容 `std::list`、`std::vector` 等容器。

---

## 🏗️ 架构设计

采用经典的三级缓存架构，逐级减少锁竞争与内存碎片：

1. **ThreadCache (线程缓存)**：每个线程独享的空闲链表。业务申请 `<= 128B` 的小对象时，直接从本地获取，无锁极速分配。
2. **CentralCache (中心缓存)**：当 `ThreadCache` 为空或溢出时，进行批量内存的分配与回收。采用桶锁（Bucket Lock）降低全局冲突。
3. **PageCache (页缓存)**：以 Page（4KB）为单位向操作系统批发内存，切分为 Span 分配给 `CentralCache`，解决大块内存碎片。

## 🛠️ 快速开始

### 1. 编译环境
- C++ 标准：C++17 及以上
- 编译器：MSVC 2019+ / GCC 9+ / Clang 10+

### 2. 基础使用
```cpp
#include "tcpool.h"

int main() {
    // 1. 初始化池子，预分配 64MB 虚拟内存防碎片
    xzh::Reserve(64 * 1024 * 1024); 

    // 2. 申请内存 (定长池，必须指定大小)
    void* ptr = xzh::TCMalloc(128);
    
    // 3. 使用内存...
    
    // 4. 释放内存
    xzh::TCFree(ptr, 128);
    
    return 0;
}
