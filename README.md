#  GM Engine

GM Engine是一个专注于游戏领域的2D窗口应用开发框架，它的核心功能与2D游戏引擎相似，但又比其自由的多。如果你想自由的开发游戏同时又想比直接用库手搓更有效率，那不妨试试这个项目。

## 架构

整体架构基于C++与luajit实现,用户主要通过编写lua脚本执行逻辑，在有扩展的情况下可以直接写C/C++代码辅助lua层执行逻辑

## 特点

1.自由
- 用户在lua层可以直接操作C层结构体的字段进行更改
- 用户可调用lua接口动态加载外部动态库实现功能扩展

2.高性能
- 在架构层面上，C++直接编译成机器码与luajit追踪编译成半字节码为GM Engine提供了不低的性能下限
- 有xclang扩展的情况下也可以在本地直接写C++/C本地编译成dll辅助lua层实现高性能逻辑(使用C结构体减少内存消耗,直接将lua层的复杂逻辑直接本地用C/C++代写等)

3.低门槛
- 想要入手GM Engine,只需要懂得lua语法以及游戏基本概念(主循环，场景，摄像机等)

4.上限极高
- 随着能力不断提升，用户从最初只会用lua写小游戏，到学习C++实现高性能实现做更大型的游戏。甚至后面学习了计算机网络和数据库，用户甚至不依赖官方实现自己手搓数据库接入和实现联机功能

5.效率
- 引擎提供游戏通用基本概念的实现:事件，实体，摄像机，场景，状态机，渲染，资源加载等让你不用再重复造基础的轮子
- 引擎还提供了标准库，比如动画库，视频库等让你的开发效率进一步提升

## 怎么使用

1.如果是使用引擎的直接下载release包，阅读WiKi中的接口规范即可开始你的项目

2.如果是想要为该引擎做插件等原因想参考源码的，请根据thridparty.txt下载对应的第3方依赖，最后下载GM Engine源码配置好编译选项即可编译运行
